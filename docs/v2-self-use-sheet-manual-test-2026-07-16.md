# V2 자가사용 시트지 수동 테스트 체크리스트

검증이 끝난 항목은 `[x]`로 변경하고, 이상이 있는 항목만 남겨 후속 수정에 사용한다.

## 사전 조건

- [ ] 원자재 재고관리에서 테스트할 원자재 LOT와 현재고를 기록한다.
- [ ] 외주 재단 테스트에 사용할 활성 외주처를 기록한다. 외주처 원자재 위치는 작업 시작 시 자동 확보된다.

## 자가사용 시트지 관리

- [ ] 신규 작업등록에서 재단 폭/길이가 투입예정/예상생산 행보다 먼저 보이고, 예상생산(매)는 직접 수정할 수 없다.
- [ ] M 단위 원자재 LOT, 투입예정 10M, 재단 폭 300mm, 재단 길이 400mm를 입력하면 예상생산이 50매로 자동 계산된다.
- [ ] 투입예정 또는 재단 폭/길이를 바꾸면 예상생산이 즉시 재계산된다.

- [ ] 내부 재단 작업을 임시저장하면 원자재 재고가 아직 차감되지 않는다.
- [ ] 내부 재단 작업을 시작하면 선택한 원자재 LOT에서 투입예정수량이 차감된다.
- [ ] 외주 재단 작업을 시작하면 사내 LOT 수량이 차감되고 같은 원자재 LOT가 외주처 위치에 증가한다.
- [ ] 외주처 원자재 위치가 미등록된 상태에서도 `가공출고/작업시작`이 정상 완료되고 위치가 자동 생성된다.
- [ ] 완료 시 `실제투입 + 반환 = 투입예정`이 아니면 저장되지 않는다.
- [ ] 완료 시 정상수량만큼 자가사용 시트지 LOT가 생성되고 원자재 원가, 실제 가공비, 총원가, 단위원가가 맞다.
- [ ] 가공중 작업을 취소하면 출고·투입된 원자재가 원래 위치와 LOT로 복원된다.
- [ ] 완료 작업은 생성된 시트지를 사용하지 않았을 때만 취소할 수 있다.

## 자가사용 시트지 재고

- [ ] 완료된 시트지 LOT에 최초 보관위치와 위치별 수량이 표시된다.
- [ ] 시트지 일부를 다른 위치로 이동하면 LOT 총잔량은 유지되고 출발/도착 위치 수량만 변경된다.
- [ ] 위치이동 이력에 출발·도착 위치, 이동수량, 위치잔량, 사유가 표시된다.
- [ ] 인쇄 초기 셋팅 또는 샘플 제작으로 사용 처리하면 시트지 잔여수량과 재고금액이 감소한다.
- [ ] 기타 목적은 메모 없이 사용 처리할 수 없다.
- [ ] 사용 이력을 취소하면 수량과 재고금액이 복원되고 `사용취소` 이력이 추가된다.
- [ ] 동일한 사용 이력을 두 번 취소할 수 없다.
- [ ] 수불 이력은 특정 시트지 LOT 선택과 관계없이 전체 LOT 이력을 최신순으로 조회하고, 검색어·수불구분·기간 및 페이지 이동이 동작한다.
- [ ] 외주작업 투입 이력에는 사용 제품, 제품 LOT, 발주 거래처, 외주작업지시번호가 표시된다.
- [ ] 일반 사용·위치이동 등 제품 제조와 연결되지 않은 이력의 사용 제품·제품 LOT·발주 거래처는 `-`로 표시된다.
- [ ] 전체 수불에서 다른 시트지 LOT의 일반 사용을 선택해도 해당 LOT 버전으로 정상 취소되며, 외주작업 투입 행은 수불 화면에서 취소할 수 없다.

## 외주 작업지시에서 자가사용 시트지 투입

- [ ] 기존 후보 LOT 선택, 묶음/개별, 판데이터, 대표품목 흐름은 그대로 동작한다.
- [ ] 투입원을 `원단 롤` 또는 `자가사용 시트지`로 선택할 수 있다.
- [ ] 자가사용 시트지는 현재고가 있는 위치별로 표시되며, 선택한 모든 제품 판 규격이 시트지 안에 들어가는 항목만 선택 목록에 표시된다(90도 회전 허용).
- [ ] 제품 판 규격보다 작은 자가사용 시트지는 선택 목록에서 제외되고 서버에서도 저장이 차단된다.
- [ ] 자가사용 시트지 선택 시 원자재 배정은 비활성화되고 시트지 LOT/위치/매수를 입력한다.
- [ ] 무지+자가사용 시트지는 재단을 건너뛰고 도무송 작업지시로 생성된다.
- [ ] 인쇄+자가사용 시트지는 재단을 건너뛰고 인쇄 작업지시로 생성된다.
- [ ] 무지+자가사용 시트지는 외주발주서 작성의 재단 후보에 표시되지 않고 도무송 외주관리 대상으로 표시된다.
- [ ] 인쇄+자가사용 시트지는 외주발주서 작성의 재단 후보에는 표시되지 않고 인쇄 후보에만 표시된다.
- [ ] 인쇄+롤 원단은 기존과 같이 재단 후보와 인쇄 후보에 모두 표시된다.
- [ ] 저장하면 선택 위치의 시트지 수량이 차감되고 외주작업 투입 이력이 생성된다.
- [ ] 작업지시 상세에서 시트지 LOT와 그 시트지를 만든 원자재 LOT·원위치·실제투입량을 확인할 수 있다.
- [ ] 작업지시 취소 시 차감한 시트지가 원래 위치로 복원되고 투입취소 이력이 생성된다.
- [ ] 원자재 재고 수불 이력의 외주작업 사용차감·사용취소 행에도 사용 제품, 제품 LOT, 발주 거래처가 표시되고 묶음은 `대표값 외 N건`으로 표시된다.

## 화면 및 동시 수정

- [ ] 원자재관리 하위에 `자가사용 시트지 관리`, `자가사용 시트지 재고` 메뉴가 표시된다.
- [ ] 다른 화면에서 같은 작업이나 시트지 재고를 먼저 변경한 뒤 기존 화면에서 저장하면 재조회 안내와 함께 중복 저장이 차단된다.
